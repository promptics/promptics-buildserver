# Rules for agents working in this repository

**This repository is public.** Everything in it is published: files, code comments, commit
messages, pull request and issue text, review comments, and the output of its workflows.

Write nothing that is internal to the organisation, not even a name, unless the code cannot work
without it:

- no names of private repositories, their issues or pull requests;
- no names of servers, hosts, cloud projects, snapshots, internal URLs, IP addresses or webhook ids;
- no people's names, logins or email addresses; commit with a GitHub noreply address;
- no other organisations, customers or partners; no prices, spend or usage figures;
- no local paths of anyone's machine, no incident stories.

Explain *what* the code does and *why*, generically. Operating notes (who uses the pool, runbooks,
decisions with their history) live in the organisation's private repositories; do not link them.

Before every commit and every pull request text, read the diff for names that break this rule.
